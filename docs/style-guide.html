Paleta de Cores

As cores são definidas como tokens HSL no CSS, permitindo temas claro/escuro. A paleta é terrosa, com rosa queimado como cor primária e verde acinzentado como secundária.

Como escrever para o Flor de Maio

  • Tom acolhedor, íntimo e literário.
  • Use itálico para títulos de livros e frases de destaque.
  • Metadados (datas, notas, rótulos) em monoespaçada, caixa alta e com letras espaçadas.
  • Mantenha espaços generosos entre seções — layout editorial e respirado.
